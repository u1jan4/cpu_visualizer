FCFS
This is the simplest scheduling algorithm where processes are executed in the order they arrive. It is non-preemptive and uses a FIFO queue. While easy to implement, it often results in high average waiting times due to the convoy effect.
SJF
SJF selects the process with the shortest CPU burst time. It can be preemptive or non-preemptive. This algorithm minimizes average waiting time but can lead to starvation for longer processes.
SRTF
This is the preemptive version of SJF. The CPU is allocated to the process with the shortest remaining burst time. It is ideal for batch systems but challenging to implement in real-time systems where burst times are unknown.
RR
In Round Robin, each process is assigned a fixed time quantum. After this time, the process is preempted, and the next process in the queue is executed. This ensures fairness and is suitable for time-sharing systems. The performance depends heavily on the size of the time quantum.
Priority
Processes are executed based on their priority. It can be preemptive or non-preemptive. While high-priority tasks are executed first, this algorithm can cause starvation for lower-priority processes unless aging is implemented.
